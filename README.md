# Mini CRM (Lead Management System)

A simple Customer Relationship Management (CRM) application built to manage and track leads. This project was created for learning full-stack web development concepts and basic CRUD operations.

## 🚀 Features

- Add new leads
- View all leads
- Update lead details
- Delete leads
- Search and manage lead information
- Simple and responsive user interface


## 📌 Purpose

This project was developed to practice building a full-stack application using the MERN stack. It focuses on implementing CRUD operations, REST APIs, and database integration rather than production-level features.

## ⚠️ Note

This is a learning project and is not intended to be a production-ready CRM. Some advanced features such as authentication, role-based access, notifications, and analytics are not included.
